第一部分：构建64个基底

理论部分梳理

构建基底的理论主要参考Eichmann三体Faddeev基底论文. 下面进行简单的整理.

欧式convention

动量

$p\cdot q=\sum_{k=1}^4 p_kq_k$, $p^2=p\cdot p$, $\slashed{p}=p\cdot \gamma$
若$p^2>0$, 向量p是类空的; 若$p^2<0$, 向量p是类时的.

Gamma矩阵

性质
  1. 厄米性: $\gamma ^\mu=(\gamma ^\mu)^\dagger$
  2. 反对易性: $\lbrace \gamma^\mu, \gamma^\nu\rbrace$
定义
  1. $\sigma^{\mu\nu}=-\frac{i}{2}[\gamma^\mu,\gamma^\nu]$
  2. $\gamma^5=-\gamma^1\gamma^2\gamma^3\gamma^4$

注: $\sigma^{\mu\nu}$前面的符号来源于欧式-闵氏度规转换.

表示

$$\gamma^k=-i\gamma _M^k=\begin{pmatrix}
0 & -i\sigma^k \newline
i\sigma^k & 0
\end{pmatrix},\ \gamma^4=\gamma _M^0=\begin{pmatrix}
\mathbb{1} & 0 \newline
0 & -\mathbb{1}
\end{pmatrix},\ \gamma^5=\gamma _M^5=\begin{pmatrix}
0 & \mathbb{1} \newline
\mathbb{1} & 0
\end{pmatrix}$$
其中, $\sigma^k$是Pauli矩阵.
$$\sigma^1=\begin{pmatrix}
0 & 1 \newline
1 & 0
\end{pmatrix},\ \sigma^2=\begin{pmatrix}
0 & -i \newline
i & 0
\end{pmatrix},\ \sigma^3=\begin{pmatrix}
1 &0 \newline
0 & -1
\end{pmatrix}$$

电荷共轭矩阵

$$C=\gamma^4 \gamma^2,\ C^T=C^\dagger=C^{-1}=-C$$
有$\overline{C}=CC^TC^T=CC^{-1}C^{-1}=C^{-1}=-C$.

对于$\gamma$矩阵, 有$\gamma^\mu=-\overline{\gamma^\mu}=-C\gamma^{\mu T}C^T$, $\gamma^5=\overline{\gamma^5}=C\gamma^{5 T}C^T$.

对于(赝)标量, (轴)矢量, 张量振幅, 定义荷共轭振幅
$$\overline{\Gamma}(p,q,P):=C \Gamma(-p,-q,-P)^T C^T$$
$$\overline{\Gamma}^\alpha(p,q,P):=-C \Gamma^\alpha(-p,-q,-P)^T C^T$$
$$\overline{\Gamma}^{\alpha\beta}(p,q,P):=C \Gamma^{\alpha\beta}(-p,-q,-P)^T C^T$$

张量积

Faddeev振幅是一个旋量四点函数(三条夸克腿, 一条束缚态腿). 一个旋量$\Psi_\alpha$有一个指标, 有四个维度; 旋量四点函数就有四个指标, 一共有$4^4=256$个维度, 我们就会有256个基底.

一个物理上比较方便的方法是利用Dirac双线性型的现成基底描述, 因为可以利用CPT及其他对称性进行约束.(当然可以选择其他分解方法, 但是不好进行物理上的约束.) Dirac双线性型有16个基底$\lbrace \unit, \gamma^\mu, \sigma^{\mu\nu}, \gamma^\mu \gamma^5, \gamma^5 \rbrace$, 所以旋量四点函数可以表示为16x16=256个基底的线性组合. 所以这些基底可以表示为两个Dirac双线性型的直积.

定义Dirac矩阵的直积:
$$(A\otimes B)_ {\alpha\beta,\gamma \delta}= A_ {\alpha\beta} B_ {\gamma \delta} $$
$$(A_1\otimes B_1)(A_2\otimes B_2)=(A_1 A_2 \otimes B_1 B_2)$$
$$(A\otimes B)^T = A^T \otimes B^T$$
$$Tr(A\otimes B) = Tr(A) Tr(B)$$

注: 这里的四个指标, 前三个指标是出射夸克腿的自旋指标, 第四个指标是入射束缚态腿的自旋指标. 通过Fierz变换可以交换指标顺序.

定义旋量四点函数电荷共轭:
$$\overline{(A\otimes B)}(p,q,P):=(C\otimes C) (A\otimes B)^T(-p,-q,-P) (C\otimes C)^T=\overline{A}(p,q,P)\otimes \overline{B}(p,q,P)$$
其中, $C=\gamma^4 \gamma^2$是电荷共轭矩阵.

动量参数

Faddeev振幅依赖于三个夸克动量$p_1, p_2, p_3$, 也可以用总动量$P$和两个相对Jacobi动量$p,q$来表示. 这里总动量$P^2=-M^2$为束缚态在壳条件. 两套动量的关系为:
$$p=(1-\xi)p_3-\xi(p_1+p_2),\ p_1=-q-\frac{p}{2}+\frac{1-\xi}{2}P$$
$$q=\frac{p_2-p_1}{2},\ p_2=q-\frac{p}{2}+\frac{1-\xi}{2}P$$
$$P=p_1 + p_2 + p_3,\ p_3=p+\xi P$$

习惯上取$\xi=\frac{1}{3}$, 于是得到
$$p=\frac{2}{3}p_3-\frac{1}{3}(p_1+p_2),\ p_1=-q-\frac{p}{2}+\frac{1}{3}P$$
$$q=\frac{p_2-p_1}{2},\ p_2=q-\frac{p}{2}+\frac{1}{3}P$$
$$P=p_1 + p_2 + p_3,\ p_3=p+\frac{1}{3} P$$

正交归一化

然后我们需要将上述动量正交化和归一化.
定义归一化动量算符: $\hat{k}=\frac{k}{\sqrt{k^2}}$.
定义横向动量投影算符: $T _k^{\mu\nu}=\delta^{\mu\nu}-\hat{k}^\mu \hat{k}^\nu$

于是我们可以构建三个正交化的动量:

  1. 第一个动量为总动量P.
  2. 将相对动量p投影到垂直于P的空间, 得到第二个动量:$p _T^\mu:=T _P^{\mu\nu}p^\nu$.
  3. 将相对动量q先投影到垂直P的空间, 再投影到垂直$p _T$的空间, 得到第三个动量:$q _t^\mu:=T _{p _T}^{\mu\nu}T _P^{\nu\lambda}q^\lambda=T _{p _T}^{\mu\nu}q _T^\nu$.

最后我们对这三个动量进行归一化, 得到最终的正交归一化动量$\lbrace\hat{p_T},\hat{q_t},\hat{P}\rbrace$, 满足
$$\hat{p _T}^2=\hat{q _t}^2=\hat{P}^2=1$$
$$\hat{p _T}\cdot \hat{q _t}=\hat{p _T}\cdot \hat{P}=\hat{q _t}\cdot \hat{P}=0$$

参数化

一个四维动量可以参数化为:
$$k^\mu=\sqrt{k^2}\lbrace \sqrt{1-z^2}\sqrt{1-y^2}\sin\phi, \sqrt{1-z^2}\sqrt{1-y^2}\cos\phi, y\sqrt{1-z^2}, z\rbrace$$

我们选择以总动量P为轴的球坐标系来参数化动量, 即
$$P=IM\lbrace0,0,0,1\rbrace$$
$$\hat{P}=\lbrace0,0,0,1\rbrace$$

假设$z_1=\hat{p}\cdot\hat{P}$, $z_2=\hat{q}\cdot\hat{P}$, 并假设$\phi _1=\phi _2=0$.
那么
$$p=\sqrt{p^2}\lbrace 0, \sqrt{1-z_1^2}\sqrt{1-y_p^2}, y_p\sqrt{1-z_1^2}, z_1\rbrace$$
$$q=\sqrt{q^2}\lbrace 0, \sqrt{1-z_2^2}\sqrt{1-y_q^2}, y_q\sqrt{1-z_2^2}, z_2\rbrace$$
假设$z0=\hat{p}_T\cdot\hat{q}_T$, 并假设$y_p=1$, 有
$$p=\sqrt{p^2}\lbrace 0, 0, \sqrt{1-z_1^2}, z_1\rbrace$$
$$q=\sqrt{q^2}\lbrace 0, \sqrt{1-z_2^2}\sqrt{1-z_0^2}, z_0\sqrt{1-z_2^2}, z_2\rbrace$$
$$p _T=\lbrace 0, 0, 1, 0\rbrace$$
$$q _T=\sqrt{q^2}\lbrace 0, \sqrt{1-z_0^2}, z_0, 0\rbrace$$
于是
$$\hat{q_t}=\lbrace 0,1,0,0 \rbrace$$
所以最后得到
$$P=IM\lbrace0,0,0,1\rbrace$$
$$p=\sqrt{p^2}\lbrace 0, 0, \sqrt{1-z_1^2}, z_1\rbrace$$
$$q=\sqrt{q^2}\lbrace 0, \sqrt{1-z_2^2}\sqrt{1-z_0^2}, z_0\sqrt{1-z_2^2}, z_2\rbrace$$
$$\hat{P}=\lbrace0,0,0,1\rbrace$$
$$\hat{p _T}=\lbrace 0, 0, 1, 0\rbrace$$
$$\hat{q _t}=\lbrace 0,1,0,0 \rbrace$$

对称性约束

对于s=1/2的束缚态, 可以考虑Parity和正反粒子对称性约束. 可以分成$(1/2)^+, (1/2)^-, \overline{(1/2)^+}, \overline{(1/2)^-}$四种情况, $\pm$代表宇称, 上划线代表正负粒子.

Parity

宇称变换是在保持自旋的基础上反转粒子的动量方向.
对于Dirac双线性型, 所有不带$\gamma^5$矩阵的双线性型都拥有正宇称, 带$\gamma^5$矩阵的双线性型都拥有负宇称(笔记P23).

正反粒子约束

正反粒子约束可以通过正负能投影算符来实现:
$$\Lambda^\pm(\hat{P})=(1\pm\hat{\slashed{P}})/2$$

证明: Dirac方程: $(i\slashed{\partial}-m)\psi=0$,
其正频平面波解: $\Psi=u(p)e^{-ip\cdot x}$, 其中 $u(p)$ 满足 $(\slashed{p}-m)u(p)=0$, 即$\slashed{p}u(p)=mu(p)$.
负频平面波解: $\Psi=v(p)e^{ip\cdot x}$, 其中 $v(p)$ 满足 $(\slashed{p}+m)v(p)=0$, 即$\slashed{p}v(p)=-mv(p)$.
所以: $\frac{m+\displaystyle\slashed{p}}{2m}u(p)=\frac{m+m}{2m}u(p)=u(p)$;
$\frac{m-\displaystyle\slashed{p}}{2m}u(p)=\frac{m-m}{2m}u(p)=0$;
$\frac{m+\displaystyle\slashed{p}}{2m}v(p)=\frac{m-m}{2m}v(p)=0$;
$\frac{m-\displaystyle\slashed{p}}{2m}v(p)=\frac{m+m}{2m}v(p)=v(p)$.
取归一化动量, 得到上述投影算符.
取了在壳条件才有不同极化, 因此正负能投影是针对束缚态外线而不是夸克内线(传播子)的.

正负能投影算符具有以下性质:

  1. $\Lambda^2 _\pm = \Lambda _\pm$;
  2. $\hat{\slashed{P}}\Lambda _\pm = \pm \Lambda _\pm$.

在旋量场里, $u(p)$代表费米子外线, $v(p)$代表反费米子外线. 我们只关注质子中子等费米子, 所以只取正能部分.
于是在束缚态所在的空间基底乘上正能投影算符, 构成如下形式基底:
$$A\otimes B\Lambda^+$$

在第一空间(diquark空间)中, 并没有正负粒子要求, 但是因为其是正交的, 我们仍然可以将其分出两大正交的子空间如下, 方便后续计算.
$$A\Lambda^+ \otimes B\Lambda^+$$
$$A\Lambda^- \otimes B\Lambda^+$$

注:
一个问题是: 只约束了束缚态取正粒子, 将正能投影算符作用在束缚态空间上, 是否会对和束缚态处于同一空间的夸克产生额外约束?

Scalar-Diquark

第一个空间是由两个夸克构成, 为了形成一个Dirac矩阵, 有一个夸克取了转置. 为了方便和夸克转置缩并, 可以在diquark空间乘一个C矩阵. 但是C矩阵具有负parity宇称, 为了保证宇称为正, 因此直接乘上$\gamma _5 C$因子, 类似于标量diquark结构形成如下基底形式.
$$A\gamma _5 C \otimes B\Lambda^+$$

这样的话我们就得到了基础的基底形式:
$$\Omega^r(P)=\Lambda^r(P)\gamma _5 C\otimes \Lambda^+(P)$$

正交基底

前面说过Dirac双线性型有16个基底$\lbrace \unit, \gamma^\mu, \sigma^{\mu\nu}, \gamma^\mu \gamma^5, \gamma^5 \rbrace$, 由于正宇称去掉含有$\gamma^5$的部分, 剩余$\lbrace \unit, \gamma^\mu, \sigma^{\mu\nu}\rbrace$现在我们将这些基底和动量结合起来构建正交基底.
很容易可以想到以下组合:
$$\Gamma _i(\hat{p _T},\hat{q _t},\hat{P})\in\lbrace \unit,\frac{1}{2}[\hat{\slashed{p} _T},\hat{\slashed{q} _t}],\hat{\slashed{p} _T},\hat{\slashed{q} _t}\rbrace$$
不含$\hat{\slashed{P}}$是因为$\hat{\slashed{P}}\Lambda^+=\Lambda^+$.

利用$\frac{1}{2}[\hat{\slashed{p} _T},\hat{\slashed{q} _t}]=\hat{\slashed{p} _T}\hat{\slashed{q} _t}-\hat{p _T}\hat{q _t}$以及正交性$\hat{p _T}\hat{q _t}=0$, 得到$\frac{1}{2}[\hat{\slashed{p} _T},\hat{\slashed{q} _t}]=\hat{\slashed{p} _T}\hat{\slashed{q} _t}$.
所以最终
$$\Gamma _i(\hat{p _T},\hat{q _t},\hat{P})\Lambda^+(\hat{P})\in\lbrace \unit,\hat{\slashed{p} _T},\hat{\slashed{q} _t},\hat{\slashed{p} _T}\hat{\slashed{q} _t}\rbrace\Lambda^+(\hat{P})$$

这样我们就构建了$4\times 4\times 2=32$个基底:
$$(\Gamma _i\otimes \Gamma _j)\Omega ^r$$
两个空间都乘$\gamma^5$(保证整体的宇称为正), 很自然可以拓展另外32个基底, 构成一共64个基底:
$$
\begin{pmatrix}
S _{ij}^r(\hat{p _T},\hat{q _t},\hat{P}) \newline
P _{ij}^r(\hat{p _T},\hat{q _t},\hat{P})
\end{pmatrix}:=
\begin{pmatrix}
\unit\otimes \unit \newline
\gamma^5\otimes \gamma^5
\end{pmatrix}
(\Gamma _i\otimes \Gamma _j)\Omega ^r
$$
这里S, P分别代表两个scalar和pseudoscalar成分, 组成到一起构成正宇称.

类似同样可以定义vector, axialvector和tensor成分的基底.
$$
\begin{pmatrix}
V _{ij}^r(\hat{p _T},\hat{q _t},\hat{P}) \newline
A _{ij}^r(\hat{p _T},\hat{q _t},\hat{P}) \newline
T _{ij}^r(\hat{p _T},\hat{q _t},\hat{P})
\end{pmatrix}:=
\begin{pmatrix}
\gamma _T^\mu\otimes \gamma _T^\mu \newline
\gamma _T^\mu\gamma^5\otimes \gamma _T^\mu\gamma^5 \newline
\sigma _T^{\mu\nu}\otimes \sigma _T^{\mu\nu}
\end{pmatrix}
(\Gamma _i\otimes \Gamma _j)\Omega ^r
$$
其中, $\gamma _T^\mu=T_P^{\mu\nu}\gamma^\nu$, $\sigma _T^{\mu\nu}= -\frac{i}{2}[\gamma _T^\mu,\gamma _T^\nu]$.
注: 这里之所以是$\gamma _T^\mu$是因为我们选择束缚态静止系. 带方向的量需要减去平行于P的分量.

这所有基底中, 只需要SP就足以表达所有64个基底, 因此VAT的这些基底全部可以用SP基底线性表示出来. 这里给出VA基底用SP基底表示的结果:

角动量本征基底

要构建角动量本征基底, 必须先构建角动量算符.

角动量算符

由于总角动量守恒, 有$\mathbf{W_j}=\mathbf{W_l}+\mathbf{W_s}$, 其中$\mathbf{ W_j}$是质子总角动量算符, $\mathbf{W_l}$是夸克相对轨道角动量算符, $\mathbf{W_s}$是夸克总自旋算符.

质子总自旋算符

质子总自旋算符(Pauli-Lubanski operator)只与质子性质有关, 所以作用在质子空间上:
$$W_j^\mu=\frac{1}{2}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu J^{\alpha\beta}$$
总自旋的平方:
$$\begin{align}
W_j^2=&W_j^\mu W_j^\mu\newline
=&\frac{1}{4}\epsilon^{\mu\nu _1\alpha _1\beta _1}\epsilon^{\mu\nu _2\alpha _2\beta _2}\hat{P}^{\nu _1} \hat{P}^{\nu _2} J^{\alpha _1\beta _1}J^{\alpha _2\beta _2}\newline
=&\frac{1}{4}\delta^{\nu _1\alpha _1\beta _1;\nu _2\alpha _2\beta _2}\hat{P}^{\nu_1} \hat{P}^{\nu_2} J^{\alpha _1\beta _1} J^{\alpha _2\beta _2}\newline
=&\frac{1}{4}(\delta^{\nu _1\nu _2}\delta^{\alpha _1\alpha _2}\delta^{\beta _1\beta _2}+\delta^{\nu _1\alpha _2}\delta^{\alpha _1\beta _2}\delta^{\beta _1\nu _2}+\delta^{\nu _1\beta _2}\delta^{\alpha _1\nu _2}\delta^{\beta _1\alpha _2}-\delta^{\nu _1\nu _2}\delta^{\alpha _1\beta _2}\delta^{\beta _1\alpha _2}\newline
&-\delta^{\nu _1\alpha_2}\delta^{\alpha _1\nu _2}\delta^{\beta _1\beta _2}-\delta^{\nu _1\beta _2}\delta^{\alpha _1\alpha _2}\delta^{\beta _1\nu _2})\hat{P}^{\nu_1} \hat{P}^{\nu_2} J^{\alpha _1\beta _1} J^{\alpha _2\beta _2}\newline
=&\frac{1}{4}( \hat{P}^\nu\hat{P}^\nu J^{\alpha \beta} J^{\alpha \beta} + \hat{P}^{\nu} \hat{P}^{\beta} J^{\alpha \beta} J^{\nu \alpha} + \hat{P}^{\beta} \hat{P}^{\nu} J^{\nu \alpha} J^{\alpha \beta}\newline
&-\hat{P}^{\nu} \hat{P}^{\nu} J^{\beta\alpha} J^{\alpha\beta}-\hat{P}^{\beta} \hat{P}^{\nu} J^{\nu\alpha} J^{\beta \alpha} - \hat{P}^\alpha \hat{P}^\nu J^{\beta \nu} J^{ \beta\alpha})\newline
=&\frac{1}{4}(J^{\alpha \beta} J^{\alpha \beta} + \hat{P}^{\nu} \hat{P}^{\beta} J^{\alpha \beta} J^{\nu \alpha} + \hat{P}^{\beta} \hat{P}^{\nu} J^{\nu \alpha} J^{\alpha \beta}\newline
&-J^{\beta\alpha} J^{\alpha\beta}-\hat{P}^{\beta} \hat{P}^{\nu} J^{\nu\alpha} J^{\beta \alpha} - \hat{P}^\alpha \hat{P}^\nu J^{\beta \nu} J^{ \beta\alpha})
\end{align}$$
由于角动量算符反对称, 有$J^{\alpha \beta}=-J^{\beta \alpha}$, 所以上式化简为:
$$W_j^2=\frac{1}{2}J^{\mu\nu}J^{\mu\nu}+\hat{P}^\mu \hat{P}^\nu J^{\mu\alpha}J^{\alpha\nu}\rightarrow j(j+1)$$
其本征值定义了总自旋j.

夸克总自旋算符

对于夸克自旋算符, 仍然使用Pauli-Lubanski operator定义, 但是作用在夸克空间上 $W_s^\mu=\frac{1}{2}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu S^{\alpha\beta}$, 并且$S^{\alpha\beta}=\frac{1}{2}\sigma^{\alpha\beta}(s=\frac{1}{2})$. 所以
$$W_s^\mu=\frac{1}{4}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu \sigma^{\alpha\beta}$$
而质子中一共有三个夸克, 所以夸克总自旋算符为:
$$W_s^\mu=\frac{1}{4}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu (\sigma^{\alpha\beta}\otimes\unit\otimes\unit+perm.)$$

最后得到:
$$W_s^2=\frac{9}{4}\unit\otimes\unit\otimes\unit+\frac{1}{4}(\sigma _T^{\mu\nu}\otimes\sigma _T^{\mu\nu}\otimes\unit+perm.)\rightarrow s(s+1)$$
其本征值定义了总自旋s.

夸克相对轨道角动量算符

有两个相对动量p, q, 每个相对动量都有一个轨道角动量算符:
$$L _{(p)}^\mu=\frac{i}{2}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu (p^\alpha \frac{\partial}{\partial p^\beta}-p^\beta \frac{\partial}{\partial p^\alpha})\unit\otimes\unit\otimes\unit$$
$$L _{(q)}^\mu=\frac{i}{2}\epsilon^{\mu\nu\alpha\beta}\hat{P}^\nu (q^\alpha \frac{\partial}{\partial q^\beta}-q^\beta \frac{\partial}{\partial q^\alpha})\unit\otimes\unit\otimes\unit$$

正交归一性

角动量本征基底满足正交归一性关系:
$$\frac{1}{4} Tr \lbrace\overline{X_{ij} ^r} X_{i’j’}^{r’}\rbrace=\delta _{ii’}\delta _{jj’}\delta _{rr’}$$

验证
  1. 基底形式为: $X=A\Lambda^r\gamma _5 C \otimes B\Lambda^+$, 先验证公共部分:
    $$\begin{align}
    \frac{1}{4}Tr\lbrace\overline{X_1} X_2\rbrace &=\frac{1}{4}Tr\lbrace(\overline{A_1\Lambda^{r_1}\gamma _5 C \otimes B_1\Lambda^+})(A_2\Lambda^{r_2}\gamma _5 C \otimes B_2\Lambda^+)\rbrace \newline
    =&\frac{1}{4}Tr\lbrace\overline{C}\overline{\gamma _5}\overline{\Lambda^{r_1}}\overline{A_1} A_2\Lambda^{r_2}\gamma _5 C \otimes \overline{\Lambda^+}\overline{B_1}B_2\Lambda^+\rbrace \newline
    =&\frac{1}{4}Tr\lbrace\overline{C}\overline{\gamma _5}\overline{\Lambda^{r_1}}\overline{A_1} A_2\Lambda^{r_2}\gamma _5 C\rbrace Tr\lbrace\overline{\Lambda^+}\overline{B_1}B_2\Lambda^+\rbrace\newline
    =&\frac{1}{4}Tr\lbrace\overline{\gamma _5}\overline{\Lambda^{r_1}}\overline{A_1} A_2\Lambda^{r_2}\gamma _5 C\overline{C}\rbrace Tr\lbrace\overline{B_1}B_2\Lambda^+\overline{\Lambda^+}\rbrace
    \end{align}$$
    利用$C\overline{C}=CC^{-1}=\unit$, $\overline{\Lambda^r}(P)=C\Lambda^r(-P)^TC^{T}=\Lambda^r(P)$, $\Lambda^{r}\Lambda^{r’}=\delta _{rr’}\Lambda^{r}$.
    $$\begin{align}
    \frac{1}{4}Tr\lbrace\overline{X_1} X_2\rbrace &=\frac{1}{4}Tr\lbrace\overline{\gamma _5}\Lambda^{r_1}\overline{A_1} A_2\Lambda^{r_2}\gamma _5 \rbrace Tr\lbrace\overline{B_1}B_2\Lambda^+\rbrace\newline
    =&\frac{1}{4}\delta _{r_1 r_2}Tr\lbrace\overline{A_1} A_2 \Lambda^{r_1}\rbrace Tr\lbrace\overline{B_1}B_2\Lambda^+\rbrace
    \end{align}$$
    正交结果最后与C无关.

代码逻辑梳理

代码块主要适用Wolfram Language编写, 实现:

  2. 验证基底正交归一性关系.

代码详见wls代码.

FeynCalc包

FeynCalc包可以进行指标缩并, gamma矩阵运算等操作, 导入FeynCalc包

预定义

定义$\Lambda^\pm(P), \Omega^\pm(P), \overline{\Omega^\pm}(P)$以及$\Gamma_i$矩阵.

  1. FeynCalc包中的$\gamma$矩阵是闵氏空间$\gamma$矩阵, 欧式电荷共轭算符C的公式需要换算到闵氏中;
  2. 电荷共轭使用FCCCT函数实现, 但是注意FCCCT只对$\gamma$矩阵有效, 不操作动量. 依据定义需要手动翻转动量, 我没有在这里定义函数部分翻转, 而在函数调用部分翻转;
  3. FCCCT中含有过多$\gamma$矩阵会报错, 所以将一个大FCCCT拆分成多个小FCCCT(注意反序).
  4. 目前代码层面不需要定义电荷共轭C矩阵, 因为在目前的几组计算中, C矩阵会被抵消合并掉, 最终结果不含C, 详见

定义完备正交SP基底

  1. 由于直积是一种特殊运算, 需要定义. 然而实际操作中我们不需要定义完整直积运算, 只需要定义出来这种运算的运算规则即可. 这里使用Fpair函数实现. 在Mathematica中这种函数是抽象函数, 只表示一种运算关系, 并不进行实际计算, 也就是$a\otimes b$会存储成表达式$Fpair[a,b]$形式;
  2. 为了节约时间, 化简计算, 在这种偏低层的部分提前使用Calc函数对表达式进行化简.

定义角动量本征基底

  1. 使用SP而非AV进行定义, 节约计算时间;
  2. 将所有的系数从Fpair中提取出来运算, 避免重复计算;
  3. 在这里进行电荷共轭的动量反转;
  4. 因为没有定义Fpair的加法运算规则, 目前整个式子仍然保持Fpair相加的格式;
  5. 前面的部分是定义基底, 定义是不会计算的. 为了节约时间, 我们完整运算一遍基底, 将他们存到变量Basis和CBasis中, 以后需要直接调用数据即可而不需要反复调用定义计算, 所以这一步计算必不可少;
  6. 为方便后续计算, 将4维张量压平成64维向量Basis64和CBasis64, 压平后对应顺序按照注释顺序进行.

规则

  1. rules: 定义动量的内积规则. 相同动量内积为1, 不同动量内积为0. “===”用于严格判断表达式而非值是否完全相同;
  2. mergeFpair: 定义Fpair的乘法规则. 两个Fpair相乘时, 系数执行普通乘法, Fpair函数内对应系数矩阵进行点乘. 若多个Fpair相乘, 只需要递归调用此规则即可;
  3. traceFpair: 定义Fpair的迹运算规则. Fpair的迹等于其系数矩阵的迹的乘积. 先用DotSimplify将矩阵中的动量内积进行简化, TR用于计算矩阵的迹.

检查正交归一关系

(更新交换性Dot规则)

  1. 0.25*ParallelMap[(Expand[#]//.mergeFpair//.traceFpair//.rules) &, Outer[Times, CBasis64, Basis64] ]; 这句代码解释如下:
  • 首先, Outer[Times, CBasis64, Basis64] 生成两个集合所有元素两两相乘的结果, 结果是一个64x64的矩阵;
  • 然后, ParallelMap[func, obj]对上一步生成的每个矩阵中的每一个元素并行进行计算, 计算内容是对obj元素使用func函数进行计算;
  • func函数的内容如下:
    • 先使用Expand[#]将形如$(Fpair[]+Fpair[]).(Fpair[]+Fpair[])$的表达式进行展开, 变成$Fpair[].Fpair[] + Fpair[].Fpair[] + …$的形式;
    • 接着递归使用//.mergeFpair对展开后的表达式进行Fpair乘法的合并, 变为$Fpair[]+Fpair[]+…$的形式;
    • 然后(迭代)使用//.traceFpair对表达式进行迹运算;
    • 最后迭代使用//.rules对迹运算后的表达式进行动量内积的简化;
  1. 为防止化简不干净, 最后对结果再进行一个FullSimplify;
  2. 后面的内容是将结果导出到Results文件夹下的Orthogonality.wls文件中, 并打印出非零元素的位置和数值.
